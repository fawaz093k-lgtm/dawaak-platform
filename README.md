# دواءك (Dawaak)

منصة B2B تربط الصيدليات بمستودعات الأدوية في سوريا.

## الميزات الرئيسية
- بحث ذكي بالاسم التجاري أو العلمي أو الشركة
- مقارنة أسعار أكثر من مستودع في نفس الشاشة
- سلة تجمع طلبات من مستودعات متعددة
- تنبيهات تلقائية عند رجوع الدواء المقطوع
- اقتراح بدائل ذكية
- تغطية حسب المنطقة
- قفل السعر لحظة تأكيد الطلب
- باقات اشتراك (Basic / Plus / Pro)
- دعم الوضع الداكن + RTL كامل

## التقنيات المقترحة
- Frontend: Next.js 14 + Tailwind CSS
- Backend: Next.js API Routes أو NestJS
- Database: PostgreSQL + Prisma
- Auth: NextAuth.js

## البدء السريع
```bash
npm install
npm run dev
```
